# Чат 3 — Бортовой контроллер ТНПА

**Стартовая фраза для нового чата:**
> Ты агент прошивки бортового контроллера проекта ТНПА. Прочитай `CLAUDE.md`, `docs/agents/03_rov_core.md`, `docs/ICD.md` (§2, §3, §5, §6, §8, §9). Работаешь в ветке `feat/rov-core`, правишь только `src/rov_core/`.

## Владею
`src/rov_core/`: `main.cpp`, `comms.h/.cpp`, `thrusters.h/.cpp`, `sensors.h/.cpp` (можно добавить `imu.h/.cpp`, `depth.h/.cpp`).

## Задача
ESP-WROOM-32, env `rov_core`. **Безопасность прежде всего.**

1. **`thrusters`**:
   - LEDC, 50 Гц, 16 бит, 6 каналов на `ESC_PINS`. Перевод мкс → duty считается от периода 20000 мкс.
   - Сразу в `setup()` все 6 каналов получают `ESC_US_NEUTRAL`, и это держится `ESC_ARM_TIME_MS`.
   - `mix(surge, yaw, heave, sway)` строго по цепочке из ICD §9: `MIX` → нормализация → `MOTOR_DIR` → `THRUST_LIMIT` → slew `ESC_SLEW_PER_S` → `ESC_DEADBAND` → мкс. Моторы с `MOTOR_ENABLED=false` всегда 1500.
   - `stopAll()` выставляет 1500 немедленно, без slew.
2. **`comms`**:
   - UART2 `LINK_BAUD` на `ROV_LINK_*`. Разбор `ControlPacket` скользящим окном, `controlPacketValid()`.
   - Хранить последний валидный пакет и `lastPacketMs`.
   - Отправка телеметрии 10 Гц через `snprintf(TELEMETRY_JSON_FMT)` в статический буфер, затем `Serial2.write`.
3. **Fail-safe** (ICD §8): если `millis() - lastPacketMs > FAILSAFE_TIMEOUT_MS`, то armed=false и `stopAll()`. Переход в armed только по фронту: пришёл пакет armed=1 после периода disarm/таймаута. Подсветка при fail-safe сохраняет последнее состояние.
4. **`sensors`** (неблокирующе, конечные автоматы):
   - MS5837-30BA: свой драйвер на `Wire` (reset, чтение PROM с проверкой CRC4, D1/D2-конверсия ~20 мс по таймеру без ожидания, расчёт со second-order компенсацией по даташиту). Глубину обнулять по среднему давлению за первые 2 с.
   - IMU через абстрактный интерфейс (`IImu`: `begin()`, `update()`, `roll()`, `pitch()`, `yawRel()`). Реализация для MPU6050/6500 (WHO_AM_I 0x68/0x70). Комплементарный фильтр для roll/pitch, yaw как интеграл gz с калибровкой смещения на старте (2 с неподвижно).
   - VBAT: `analogReadMilliVolts(VBAT_ADC_PIN)` → делитель → `VBAT_CAL_K`, скользящее среднее.
   - Если датчик не найден, узел работает дальше, в логе пишется предупреждение, а в телеметрии остаются последние значения (0).
5. **Подсветка:** `LIGHT_PIN` = бит light последнего валидного пакета.
6. **Индикатор `STATUS_LED_PIN`:** медленно мигает — нет связи; горит — связь, disarm; быстро мигает — armed.
7. **Лог в USB Serial** раз в 1 с: пакеты/с, ошибки CRC, armed, мкс по 4 моторам, статус датчиков.

Опционально, после согласования с лидом: управление из ядра 1 (FreeRTOS-задача 100 Гц для comms + thrusters), датчики в `loop()` на ядре 1/0.

## Без железа
ESC можно заменить сервомашинкой или осциллографом/логическим анализатором. Пакеты подаются с ПК через USB-UART на GPIO16 (Python-скрипт с `controlPacketSeal`-логикой). Fail-safe проверяется выдёргиванием провода: в течение 500 мс должно стать 1500 мкс.
