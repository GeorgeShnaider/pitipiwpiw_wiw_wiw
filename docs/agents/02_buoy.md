# Чат 2 — Надводный буй

**Стартовая фраза для нового чата:**
> Ты агент прошивки буя проекта ТНПА. Прочитай `CLAUDE.md`, `docs/agents/02_buoy.md`, `docs/ICD.md` целиком. Работаешь в ветке `feat/buoy`, правишь только `src/buoy/`.

## Владею
`src/buoy/*` (`main.cpp`, по желанию `web.h/.cpp`, `link.h/.cpp`, `video.h/.cpp`).

## Задача
ESP-WROOM-32, env `buoy`. Библиотеки: ESP32Async/ESPAsyncWebServer + AsyncTCP, ArduinoJson 7.

1. **Wi-Fi AP** по константам `WIFI_AP_*` из `config.h`, статический IP 192.168.4.1. Отключить энергосбережение Wi-Fi (`WiFi.setSleep(false)`).
2. **HTTP:** `/` отдаёт `index.html` из LittleFS (если есть `index.html.gz`, отдавать его с `Content-Encoding: gzip`). Для любых других путей делать редирект на `/` (помогает captive-проверкам Android).
3. **WebSocket `/ws`** (контракт №1):
   - разбор `cmd` в статический `JsonDocument` из буфера сообщения; фрагментированные сообщения отбрасывать;
   - сохранять последнюю команду и время `lastCmdMs`;
   - ограничить число клиентов: управляет последний подключившийся, остальные только смотрят.
4. **Канал вниз (контракт №2):** UART2 `LINK_BAUD`, пины `BUOY_LINK_*`. Таймер 20 Гц: собрать `ControlPacket` из последней команды → `controlPacketSeal` → `Serial2.write`. Если `millis() - lastCmdMs > BUOY_WS_TIMEOUT_MS`, отправлять armed=0 и нули.
5. **Канал вверх (контракт №3):** читать UART2 в статический буфер `TELEMETRY_MAX_LEN` до `\n`. При переполнении сбрасывать строку до следующего `\n`. Готовую строку отправлять `ws.textAll()`.
6. **Видео (контракт №4):** UART1 RX `BUOY_VIDEO_RX_PIN`, `VIDEO_BAUD`, `setRxBufferSize(BUOY_VIDEO_RXBUF)` **до** `begin`. Разбор конечным автоматом (поиск магии → заголовок → JPEG в статический буфер `VIDEO_MAX_FRAME` → CRC16). Валидный кадр отправлять `ws.binaryAll()` только тем клиентам, у которых очередь не полна (`client->canSend()` / `queueIsFull()`), иначе пропускать.
7. **Диагностика** в `Serial` (USB) раз в 5 с: число клиентов, cmd/с, пакетов вниз/с, строк телеметрии/с, видеокадров ок/битых, свободная куча.
8. `ws.cleanupClients()` раз в секунду.

## Без железа ТНПА
Подключить USB-UART к пинам 16/17 и проверить скриптом на ПК, что пакеты идут 20 Гц с верным CRC, а строки телеметрии из терминала появляются в WebApp. Для видео можно отправить кадры с ПК через второй USB-UART (скрипт кладётся в отчёт, а в `tools/` — через запрос лиду).

- [ ] Куча стабильна при 10 минутах работы с видео (лог раз в 5 с).
- [ ] Отчёт лиду с замерами: задержка cmd → UART, к/с видео.
