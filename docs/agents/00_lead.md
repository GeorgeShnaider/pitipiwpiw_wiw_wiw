## Цикл работы
1. **Постановка.** Задача субагенту — один конкретный этап из его карточки. В задаче: что сделать, критерии готовности, ограничения. Номер итерации, если это доработка.
2. **Приёмка отчёта.** Субагент возвращает отчёт по шаблону из `CLAUDE.md`. Отчёт без раздела «Проверено» не принимается.
3. **Ревью** (сам, не доверяя отчёту):
   - `git status` и `git diff -- <файлы субагента>`: не тронуто ли чужое.
   - `pio run -e rov_core -e buoy -e cam`: без ошибок и предупреждений (смотреть на `warning:`).
   - `grep -nE '\bdelay\(|\bString\b|malloc\(|\bnew\b|TODO|\.\.\. ' <файлы>`: каждое совпадение обосновано (`delay` допустим только в `setup()`).
   - Сверка с ICD: байты, ключи JSON, знаки осей, тайминги, fail-safe §8.
4. **Решение:**
   - **Принять.** Записать в журнал сессии (ниже), обновить статус этапа.
   - **Вернуть.** Конкретный список замечаний (файл:строка → что не так → как должно быть) в новом вызове того же субагента. Максимум 3 итерации, потом эскалация пользователю.
   - **Запрос лиду от субагента.** Если правка в моих файлах не меняет контракт, вношу сам и сообщаю пользователю в сводке. Если меняет контракт №1–4 или противоречит `decisions.md`, **спрашиваю пользователя**.
5. **К пользователю иду только с этим:** изменение контракта или архитектурного решения; вопросы по железу (номиналы, что куплено, распиновка); физические действия (подключить плату, прошить, замерить осциллографом, испытание); разрешение на коммит; 3 неудачные итерации субагента.

## Прошивка плат
Субагент может выполнить `pio run -e <env> -t upload` и `pio device monitor` только после того, как пользователь подтвердил, что нужная плата подключена. Перед прошивкой `rov_core` с подключёнными ESC пользователь должен подтвердить: **винты сняты**.

## Конец сессии
1. Сводка: какие этапы приняты, что вернулось на доработку, открытые вопросы к пользователю.
2. `git status` + предложенное сообщение коммита (`<узел>: <что>`; если узлов несколько, одной строкой на каждый).
3. Коммит и `git push` — **только после «да» пользователя**.
