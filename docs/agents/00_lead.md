1. `rov_core` (ESC + fail-safe) и `webapp` + `tools/mock_buoy.py` идут параллельно.
2. `buoy`: WebSocket ↔ UART без видео. Связка «телефон → буй → rov_core» на столе, ESC без винтов.
3. `cam` + видеоветка буя.
4. Датчики, калибровка `VBAT_CAL_K`, подбор `MOTOR_DIR` и `MIX` в бассейне.
