## Задача
Однофайловый WebApp (HTML + CSS + JS в одном файле, **без CDN, шрифтов и внешних ресурсов**: у телефона в сети буя нет интернета). Целевой экран — смартфон в **альбомной** ориентации, управление двумя большими пальцами.

### Функции
1. **Два виртуальных джойстика** (Pointer Events, мультитач):
   - левый: вертикаль `surge`, горизонталь `yaw`;
   - правый: вертикаль `heave`, горизонталь `sway`;
   - возврат в 0 при отпускании, мёртвая зона ~5%, плавная кривая (экспонента).
2. **Кнопки:** ARM/DISARM и СВЕТ. **ARM** — только удержанием ~1 с, чтобы не взвести случайно; **DISARM** — мгновенно, одним касанием (безопасность важнее).
3. **Видео:** фон на весь экран. Принимает бинарные WS-сообщения (JPEG) → `Blob` → `URL.createObjectURL` → `<img>` и вызывает `revokeObjectURL` для предыдущего кадра. Показывает счётчик к/с.
4. **Телеметрия поверх видео:** глубина, температура, напряжение (цвет по порогам 14.0/13.2 В), крен/дифферент (простой авиагоризонт), относительный курс с подписью «отн.».
5. **Связь:** `ws://<location.host>/ws`. Команда отправляется **строго каждые 50 мс** (heartbeat), формат как в контракте №1. Автопереподключение раз в 1 с. Индикатор связи: возраст последней телеметрии > 1 с означает «НЕТ СВЯЗИ».
6. **Fail-safe:** при `visibilitychange` → hidden, `onclose`, `onerror` сбрасывать armed=false и оси в 0.
7. Режим полного экрана по кнопке, запрет масштабирования и выделения, `touch-action: none`.

### Ограничения
- Размер `index.html` не больше 100 КБ (в LittleFS он кладётся как есть, буй может отдавать gzip-версию).
- Никакого фреймворка: только чистый JS.
- Ключи JSON и знаки осей — строго по ICD.

## `tools/mock_buoy.py`
Python 3, единственная зависимость `websockets` (или `aiohttp`). Поднимает на ПК:
- HTTP, отдающий `data/index.html`;
- WebSocket `/ws`: печатает принятые cmd с частотой и проверяет формат, шлёт синтетическую телеметрию 10 Гц и тестовые JPEG-кадры (сгенерированные Pillow или из папки);
- режим `--drop` для проверки индикатора потери связи.

`tools/README.md` описывает, как открыть WebApp с телефона в той же Wi-Fi сети.
